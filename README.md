# BRAND — Landing Page

Адаптивный лендинг, разработанный в рамках тестового задания.

Проект реализован на чистом **HTML, CSS и JavaScript**, без использования сборщиков и фреймворков.

## Технологии

* HTML5
* CSS3
* JavaScript (ES6+)
* Responsive Design
* BEM-подобная структура классов
* `localStorage`
* `intl-tel-input`

## Реализованные блоки

* Hero-секция с CTA
* Обратный отсчёт на 15 минут
* Sticky CTA на мобильных и десктопных устройствах
* Блок преимуществ
* Слайдер отзывов с поддержкой свайпа на мобильных устройствах
* FAQ-аккордеон
* Блок «О нас»
* Многошаговая форма заявки
* Валидация имени, email и номера телефона
* Выбор страны и валидация номера телефона
* Чекбокс согласия
* Success-модальное окно после отправки формы
* Адаптивная верстка для мобильных, планшетов и десктопов

## Таймер

На странице установлен обратный отсчёт продолжительностью **15 минут**.

Время начала таймера сохраняется в `localStorage`, поэтому при обновлении страницы отсчёт продолжается с текущего значения.

**Дополнительная особенность:** при клике непосредственно на таймер обратный отсчёт запускается заново с **15:00**.

После завершения отсчёта текст CTA-кнопки автоматически меняется на **«Последний шанс»**.

## Форма

Форма состоит из двух шагов:

**Шаг 1**

* Имя
* Email

**Шаг 2**

* Номер телефона
* Согласие с условиями

Валидация выполняется без перезагрузки страницы.

После успешной отправки отображается модальное окно **«Заявка принята»**.
